## Usage Tutorial
1. **Download the micro app zip package**

   Select the micro app you need and click the download button to get the zip package.

2. **Install the micro app**

   Open Sun-Panel v2.0.0+ and do the following:
   - Click the system app icon in the top right corner
   - Find "Micro App Management"
   - Click the "Offline Install" button
   - Upload the downloaded micro app zip package

3. **Use the micro app**

   After installation is complete:
   - Refresh the page
   - Find the "Add Micro App Widget" button in the group toolbar
   - Select the installed micro app to use it
